# PC Remote

Le projet est en cours de refonte.

## Cible

- application desktop Windows avec interface Tauri ;
- application mobile React Native et TypeScript ;
- communication directe entre le mobile et le desktop sur le réseau local ;
- installateur desktop `.exe` et application Android `.apk`.

Le backend distant et l'ancien protocole Socket.IO sont retirés du produit.
Consulter `todo.md` pour suivre les étapes de la refonte.
